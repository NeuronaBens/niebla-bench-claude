# Festival de Cine Niebla · 3ª edición

Sitio del festival: portada, programa filtrable, ficha de cada película e itinerario personal que se guarda en el navegador y se comparte con un link.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # build de producción (todo estático)
npm start
```

Los datos salen de `data/programa.json` y no se modifican. Ver `ENTREGA.md` para decisiones y pendientes.
