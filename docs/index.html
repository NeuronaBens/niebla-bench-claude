Benchmark · 8 architectures in 2 rounds · September 2026

Which Claude combination builds best?

Eight ways of combining Opus 5, Sonnet 5, Fable 5.1 and Haiku 4.5 got the same brief: the website for a small film festival in a Chilean port, with an itinerary that flags overlapping screenings and walks between venues that are too short. I measured what each one cost, how long it took and how good the result was.

    Results

    Judge score = 35% alignment + 35% creativity + 30% execution, with both judges scoring all 8 sites together and blind. API cost = the real tokens of each run × official API prices (checked 2026-09-15); the runs were actually paid with a Max plan. Net time = wall-clock time minus waits for manual permission approvals.

    How it was done

    • The taskA client brief (3-day festival, 24 films, 39 screenings, 4 venues) and an identical programa.json for every run, with deliberate traps: screenings that end after midnight, post-screening Q&As, sold-out screenings, and transfers that are too short to walk. Next.js + TypeScript, no component libraries, no external images, no emojis, no ratings.
    • Round 1Opus alone · Fable alone · Opus free to use subagents · Opus plans and reviews while Sonnet codes, in separate chats, with an orchestrator passing work between them.
    • Round 2Fable free to use subagents · Fable → Opus → Sonnet · Fable leading a Haiku chat · Opus + Sonnet again, this time coordinating themselves: each chat messages the next and waits in the background without spending tokens.
    • ConditionsHigh effort everywhere, one review round in the multi-role setups, and each architecture in its own git worktree from the same commit, with the same dependencies.
    • MetricsTokens, calls, tools and timings come from the local Claude Code transcripts. Build, lint, lines of code and constraint checks come from a script run on each branch. All 8 build with no errors or warnings and none added dependencies.
    • EvaluationGabriel tried the sites knowing which was which. The AI judges scored all 8 together, blind, with a rubric written before any results existed.

    Limitations

    • One run eachEach architecture ran once. There is randomness, and another run could reorder things.
    • Chilean-flavored briefThe brief deliberately uses Chilean slang. Sites that picked up the local tone amplified it: that counts toward alignment, but it reads oddly outside Chile.
    • Humans in the loopIn round 1 Opus + Sonnet, the orchestrator passed work between chats. In round 2, Gabriel approved permissions by hand and wrote twice to the Haiku chat. The orchestrator also nudged Fable in Fable → Opus → Sonnet when its turn was cut off before closing.
    • Permissions and timingRound 2 chats started in manual mode, and Haiku does not support auto mode, so they piled up hours of waiting. Net time removes those waits (pauses over 10 minutes inside a turn), but not short ones.
    • Possible Opus biasUnconfirmed. Between about September 14 and 17, 2026 — the window these runs fall in — community reports described Anthropic silently routing some Claude Code users to a newer Opus variant, nicknamed "Opus 5.2" or "Opus-Next". Anthropic has not confirmed it. The transcripts only ever record claude-opus-5, so such routing would leave no trace and there is no way to tell which variant served each call. If some Opus runs were served by a newer model, that would favor the Opus architectures here.
    • Extrapolated costPaid with a Max plan. The cost is what those tokens would have cost on the API, with the 1-hour cache that Claude Code uses.
    • Imperfect judgesGabriel's score is not blind. The judges are, but Opus and Fable also competed, and they judged screenshots and page text rather than browsing the sites.
    • UnfinishedFable → Sonnet → Haiku was stopped before closing and is excluded from the comparison.
